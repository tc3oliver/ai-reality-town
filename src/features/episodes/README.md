# Episodes feature (placeholder)

## Future responsibility
Present the world's narrative as discrete episodes, derived from canon events via the
story projection.

## Boundary with the Canon Read Model
- Episodes are a **read model** derived from canon; they never write canon.
- Episode generation may use an LLM, but only to *propose* episode framing; the canon
  history itself is never edited by this layer.
